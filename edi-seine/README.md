# hrl-edi-template

This is a template repository for publishing data on the Environmental Data Initiative (EDI)
developed to support the [Healthy Rivers and Landscapes Program](https://resources.ca.gov/Initiatives/Voluntary-Agreements-Page).

This is part of a suite of resources and tools developed by the program to facilitate
data publication including:

- [edi-hrl-pub-example](https://github.com/lucy-dwr/edi-hrl-pub-example) an example
of how to use this template repository
- [hrlpub](https://flowwest.github.io/hrlpub/) an R package containing utility 
functions to streamline the publication of data
- [hrl documentation hub](https://lucy-dwr.github.io/hrl-docs/) central hub for 
documentation, standards, and learning materials that support the data engineering 
and data science components of the HRL Science Program.

**How to use this template**

On GitHub, navigate to the [main page](https://github.com/FlowWest/hrl-edi-template) 
of the repository. Click on the green button in the upper left called "Use this template"
and selected "Create a new repository"
